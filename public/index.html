Curriculum Architecture & Lecture Modules

A rigorous full-time syllabus advancing from web fundamentals to asymptotic proofs, binary trees, and full-stack cloud engineering.

Week 1 • Web Foundations

HTML5, Semantic UI & Responsive Design

Document hierarchy, semantic structuring, modern CSS box models, and responsive mobile flex layouts.

Week 2 • Programming Logic

Computational Logic, Variables & Control Flow

Memory allocation, primitive mutability, truth tables, branching logic, loops, and functional modularity.

Week 3 • Linear Structures

Array Invariants, Two-Pointer & Sliding Window

Contiguous memory, offset math, multi-pointer optimizations, and reducing $O(N^2)$ brute search to $O(N)$ linear scans.

Week 4 • Hash Tables

Hash Maps, Frequency Tables & Big-O Asymptotics

Deterministic hashing, collision resolution, space-time tradeoffs, and formal mathematical growth orders ($O, \Omega, \Theta$).

Week 5 • Recursion & Trees

Recursive Call Stacks & Binary Search Trees

Stack frame decomposition, base invariants, logarithmic divide-and-conquer ($O(\log N)$), and tree traversals (BFS/DFS).

Week 6 • Full-Stack Systems

RESTful APIs, PostgreSQL Databases & Cloud Deployments

Node.js event loop, asynchronous I/O, relational SQL schemas, parameterized security, and automated cloud deployments.

Week 7 • Capstone & Honors

National Software Showcase & Official Honors Graduation

Engineering team sprints, production stress-testing, public Demo Day technical presentations, and presentation of the Diploma of Honors.
